# Quentro Tickets

Dark wallet for BTS World Tour tickets (Lima + La Plata).

## Use on your phone

Open this link:

**https://emma-dev4.github.io/quentro-clonee/**

Add to Home Screen from Safari or Chrome for a full-screen pass.

## Source

Public repo: https://github.com/emma-dev4/quentro-tickets

## What’s inside

- My Tickets list (Upcoming / Past)
- Lima (7, 9, 10 Oct 2026) and La Plata (24 Oct 2026)
- 2 entradas on each ticket
- Pass view with poster, QR, Más info, and Transferir
